ساخت internal.bin

کانفیگ‌های خصوصی را همین‌جا در مرورگر رمز می‌کند. هیچ چیزی جایی فرستاده نمی‌شود — این صفحه اصلاً کد شبکه ندارد. با اینترنت قطع هم کار می‌کند.

مرورگر اجازه رمزنگاری نمی‌دهد

این فایل را روی کامپیوتر ذخیره کن و مستقیم با دوبار کلیک بازش کن (آدرس باید با file:// شروع شود)، یا از Chrome / Firefox / Edge استفاده کن.

۲ رمز عبور

همین رمز را کاربر در تب «داخلی» وارد می‌کند. هیچ‌جا ذخیره نمی‌شود — رمز خودِ کلید است، برای همین اپ بدون اینترنت بازش می‌کند. اگر گمش کنی، این بسته برای همیشه بسته می‌ماند.

 
۳ بساز
۴ بعدش چه کار کنم
  1. در گیت‌هاب برو به V2rayNG/app/src/main/assets/
  2. Add file → Upload files و internal.bin را بگذار
  3. Commit — همین. هیچ Secret‌ای لازم نیست.
  4. بیلد بعدی این بسته را همان‌طور که هست داخل APK می‌گذارد.

نکته‌ی امنیتی: کامیت کردن این فایل در مخزن عمومی اشکالی ندارد — بدون رمز فقط نویز است. ولی هر کسی که رمز را دارد می‌تواند کانفیگ‌ها را از گوشی خودش بیرون بکشد؛ هیچ قفل سمت‌کاربر جلوی این را نمی‌گیرد.
